### **“DevOps Interview English Cheat Sheet”**

| Hindi me meaning                         | English line                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| Mujhe abhi yaad nahi aa raha             | **I don't remember right now.**                                                |
| Mujhe iska idea hai, but exact yaad nahi | **I have an idea about it, but I don't remember the exact details right now.** |
| Mujhe nahi pata                          | **I'm not sure about that.**                                                   |
| Maine ye practically kiya hai            | **I have worked on this practically.**                                         |
| Maine directly kaam nahi kiya            | **I haven't worked on this directly, but I have basic knowledge of it.**       |
| Maine lab me practice ki hai             | **I have practiced this in my lab environment.**                               |
| Ek minute sochne dijiye                  | **Let me think for a moment.**                                                 |
| Main explain karta hoon                  | **Let me explain it.**                                                         |
| Simple words me                          | **In simple terms...**                                                         |
| Iska main purpose hai                    | **The main purpose of this is...**                                             |
| Iska use isliye hota hai                 | **It is mainly used for...**                                                   |
| Ye depend karta hai                      | **It depends on the requirement.**                                             |
| Exact answer nahi pata                   | **I'm not sure about the exact answer.**                                       |
| Iska answer ho gaya                      | **That covers the answer.**                                                    |
| Bas itna hi                              | **That's it.**                                                                 |
| Aage kuch nahi hai                       | **That's all from my side.**                                                   |
| Kya aap question repeat kar sakte hain?  | **Could you please repeat the question?**                                      |
| Thoda clearly bataiye                    | **Could you please elaborate on the question?**                                |
| Maine ye use kiya hai                    | **I have used this in my project.**                                            |
| Mere project me iska use hua             | **We used this in our project.**                                               |
| Production me                            | **In our production environment...**                                           |
| Hamare environment me                    | **In our environment...**                                                      |
| Mere experience ke according             | **Based on my experience...**                                                  |
| Agar main sahi samajh raha hoon          | **If I understand the question correctly...**                                  |
| Main example se explain karta hoon       | **Let me explain this with an example.**                                       |

### IMP Sentance

> **“I know this, but I don't remember the exact details right now.”**

> **“I have some understanding of this, but I haven't worked on it extensively.”**

"answer pura ho gaya then bus itana hi"

> **“That covers my answer.”**
> **“That's it.”**
> **“That's all from my side.”**

### Most important 10 lines 🧠

```text
1. Let me explain it.

2. In simple terms...

3. The main purpose of this is...

4. Based on my experience...

5. In our environment...

6. Let me explain this with an example.

7. I have worked on this practically.

8. I have basic knowledge of this, but I haven't worked on it extensively.

9. I don't remember the exact details right now.

10. That covers my answer.
```
