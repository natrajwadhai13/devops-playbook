# Phase 0 — Project Design

Perfect. Ab hum **NexCart** ka complete design freeze karte hain. Is phase me **koi coding/deployment nahi** hoga. Pehle architecture clear karenge, taki Phase 1 se files systematically ban sakein.

## 0.1 Project Identity

**Project Name:** NexCart

**Full Name:**
**NexCart – Cloud-Native Multi-Tier E-Commerce & Order Management Platform**

**Primary goal:**
Ek production-style application banana jisme DevOps, Cloud, Kubernetes, CI/CD, Security aur Observability ka end-to-end hands-on practice ho.
