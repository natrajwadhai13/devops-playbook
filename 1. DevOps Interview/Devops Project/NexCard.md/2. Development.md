# Phase 1 — Application Development

Ab actual **NexCart** banana start karte hain. Is phase me hum **DevOps tools nahi**, pehle ek clean, working multi-tier application banayenge. Baad me isi application ko Docker → Kubernetes → Helm → ArgoCD → Azure AKS tak le jayenge.

## Phase 1 ka target

End of Phase 1:

```text
NexCart
│
├── Frontend
│
├── API Gateway
│
├── User Service
├── Product Service
├── Order Service
├── Payment Service
└── Notification Service
```

Aur:

```text
Frontend
   ↓
API Gateway
   ↓
Microservices
   ↓
Databases
```

### Technology

* Java
* Spring Boot
* Maven
* REST API
* JSON
* PostgreSQL
* MySQL
* Redis
* HTML/CSS/JavaScript

# 1.1.4 Important Decision — Java Architecture

Hum har service ko **independent Spring Boot Maven project** rakhenge.

Example:

```text
application/
│
├── api-gateway/
│
├── user-service/
│
├── product-service/
│
├── order-service/
│
├── payment-service/
│
└── notification-service/
```

Iska fayda:

```text
User Service
   ↓
independent build

Product Service
   ↓
independent build

Order Service
   ↓
independent build
```

Later Docker:

```text
user-service:1.0
product-service:1.0
order-service:1.0
```

Aur Kubernetes:

```text
user-service deployment
product-service deployment
order-service deployment
```

## Abhi aapka task

Sirf ye 3 commands run karein:

```powershell
mkdir nexcart
cd nexcart
mkdir application
```

Phir:

```powershell
cd application
```

Aur ye output bhejein:

```powershell
java -version
mvn -version
git --version
```

**Abhi koi Spring Boot file manually mat banaiye.**

Aapka output milne ke baad hum **1.2 — Parent Maven + User Service ka actual code** banayenge. Is tarah har checkpoint verify hota rahega aur project ke beech me files/architecture mismatch hone ka chance bahut kam rahega.
