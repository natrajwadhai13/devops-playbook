# **Version**

Que- Which Kubernetes version have you worked on?

## 📌 Major Kubernetes Releases Timeline

- **v1.0** → July 2015 (first stable release)
- **v1.1 – v1.4** → 2015–2016 (early features like deployments, namespaces, RBAC)
- **v1.5 – v1.9** → 2016–2017 (StatefulSets, CRDs, improved networking)
- **v1.10 – v1.14** → 2018–2019 (CoreDNS default, Pod priority/preemption, Windows node support)
- **v1.15 – v1.19** → 2019–2020 (Ephemeral containers, Ingress API improvements, CSI migration)
- **v1.20 – v1.24** → 2020–2022 (Dockershim removal, CronJobs GA, PodSecurity admission)
- **v1.25 – v1.29** → 2022–2023 (PodSecurity replaces PSP, CSI volume expansion, sidecar containers)
- **v1.30 – v1.34** → 2024–2025 (Gateway API GA, NodeSwap, better autoscaling, scheduling policies)
- **v1.35 – v1.37** → 2025–2026 (latest supported series, with 1.37.0 released Aug 2026)

## 🔑 Current Supported Versions

- **1.37.0** (latest, Aug 2026)
- **1.36.x** (patches until mid‑2027)
- **1.35.x** (patches until early‑2027)

Older versions (≤1.34) are **end‑of‑life** and not maintained anymore.
