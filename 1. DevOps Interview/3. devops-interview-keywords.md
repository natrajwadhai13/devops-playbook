## 1. Git

### ⭐ Important Keywords

`clone` → `init` → `status` → `add` → `commit` → `push` → `pull` → `fetch`  
`branch` → `checkout` → `switch` → `merge` → `rebase` → `stash` → `tag`  
`remote` → `log` → `diff` → `reset` → `revert` → `cherry-pick`

### ⭐ Basic Commands

```bash
git clone <repo-url>
git status
git add .
git commit -m "message"
git push origin main
git pull origin main
git fetch
git branch
git switch -c feature/login
git merge feature/login
git stash
git log --oneline
```

### Short Memory

```text
clone  → Get repository
add    → Stage changes
commit → Save changes locally
push   → Send commits to remote
pull   → Fetch + merge remote changes
fetch  → Download remote changes only
merge  → Combine branches
rebase → Reapply commits on another base
stash  → Temporarily save changes
```

## 3. Bash / Shell Scripting

### ⭐ Important Keywords

| ⭐ Keywords & Commands                           | ⭐ Short Memory                              |
| ------------------------------------------------ | -------------------------------------------- | ---------- | -------------------- |
| `#!/bin/bash` · `set -euo pipefail`              | **Script safety** → strict error handling    |
| `variable` · `export` · `local`                  | **Variables** → store/pass values            |
| `if` · `elif` · `else` · `[[ ]]`                 | **Conditions** → decision making             |
| `for` · `while` · `until`                        | **Loops** → repeat commands                  |
| `case`                                           | **Switch** → multiple conditions             |
| `function` · `return`                            | **Functions** → reusable logic               |
| `$0` · `$1` · `$@` · `$#`                        | **Arguments** → script inputs                |
| `$?` · `$$` · `$!`                               | **Runtime** → exit code, PID, background PID |
| `-f` · `-d` · `-e` · `-r` · `-w` · `-x`          | **Tests** → file/directory/permissions       |
| `echo` · `printf` · `read`                       | **Input/Output**                             |
| `exit` · `return`                                | **Exit handling**                            |
| `&&` · `                                         |                                              | `·`;`·`\|` | **Command chaining** |
| `>` · `>>` · `2>` · `2>&1`                       | **Redirection**                              |
| `grep` · `awk` · `sed` · `cut` · `sort` · `uniq` | **Text processing**                          |
| `find` · `xargs`                                 | **File processing**                          |
| `$(command)`                                     | **Command substitution**                     |
| `source file.sh` · `. file.sh`                   | **Load another script**                      |
| `trap`                                           | **Cleanup/error handling**                   |
| `command -v`                                     | **Check command availability**               |
| `getopts`                                        | **Parse script options**                     |
| `curl` · `systemctl` · `journalctl`              | **DevOps automation**                        |

### ⭐ Basic Script

```bash
#!/bin/bash

set -euo pipefail

APP_NAME="myapp"
APP_FILE="$APP_NAME.jar"

if [[ -f "$APP_FILE" ]]; then
    echo "Application file exists"
else
    echo "Application file not found"
    exit 1
fi

echo "Script completed successfully"
```

### ⭐ Arguments & Exit Codes

```bash
#!/bin/bash

APP_NAME="$1"

if [[ -z "$APP_NAME" ]]; then
    echo "Usage: $0 <application-name>"
    exit 1
fi

echo "Application: $APP_NAME"
echo "Arguments: $@"
echo "Count: $#"
```

```text
$0   → Script name
$1   → First argument
$@   → All arguments
$#   → Number of arguments
$?   → Previous command exit status
$$   → Current script PID
$!   → Last background process PID
```

### ⭐ Functions

```bash
#!/bin/bash

set -euo pipefail

check_service() {
    local service="$1"

    if systemctl is-active --quiet "$service"; then
        echo "$service is running"
    else
        echo "$service is not running"
        return 1
    fi
}

check_service nginx
```

### ⭐ Deployment-Style Script

```bash
#!/bin/bash

set -euo pipefail

APP_NAME="myapp"
APP_DIR="/opt/$APP_NAME"
LOG_FILE="/var/log/${APP_NAME}-deploy.log"

log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') - $*" | tee -a "$LOG_FILE"
}

cleanup() {
    log "Deployment script finished"
}

trap cleanup EXIT

log "Starting deployment"

if [[ ! -d "$APP_DIR" ]]; then
    log "ERROR: Application directory not found"
    exit 1
fi

cd "$APP_DIR"

./stop.sh
./backup.sh
./start.sh

if systemctl is-active --quiet "$APP_NAME"; then
    log "Deployment completed successfully"
else
    log "ERROR: Application failed to start"
    exit 1
fi
```

### ⭐ Useful Production Patterns

```bash
# Check command
command -v docker >/dev/null || {
    echo "Docker not installed"
    exit 1
}

# Check file
[[ -f "$CONFIG_FILE" ]] || exit 1

# Check directory
[[ -d "$APP_DIR" ]] || mkdir -p "$APP_DIR"

# Run command only if previous succeeds
./backup.sh && ./start.sh

# Run fallback if command fails
curl -f "$HEALTH_URL" || echo "Health check failed"

# Redirect stdout + stderr
./deploy.sh > deploy.log 2>&1

# Run in background
./backup.sh &

# Capture command output
STATUS=$(systemctl is-active nginx)
```

### ⭐ Short Memory

```text
set -euo pipefail → Safer scripts
$?               → Previous command exit status
$0               → Script name
$1               → First argument
$@               → All arguments
$#               → Argument count
$$               → Current PID
$!               → Background PID

-f               → File exists
-d               → Directory exists
-r/-w/-x         → Read/Write/Execute

&&               → Run if success
||               → Run if failure
|                → Pipe output
>                → Redirect/overwrite
>>               → Append
2>               → Redirect errors
2>&1             → stderr → stdout

$(command)       → Command substitution
set -e           → Exit on error
set -u           → Error on unset variable
pipefail         → Pipeline failure detection
trap             → Cleanup/signal handling
```

### ⭐ Interview Focus

```text
set -e vs set -euo pipefail
$@ vs $*
$? vs $!
"$@" and quoting
[ ] vs [[ ]]
exit vs return
&& vs ||
> vs >> vs 2>&1
trap usage
shell script debugging
cron + shell script
production deployment script
health-check script
rollback script
```

## 4. Docker

### ⭐ Important Keywords

`FROM` → `WORKDIR` → `COPY` → `ADD` → `RUN` → `ENV` → `ARG`  
`EXPOSE` → `CMD` → `ENTRYPOINT` → `USER` → `VOLUME` → `HEALTHCHECK`

### ⭐ Dockerfile — Basic

```dockerfile
FROM node:22-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install

COPY . .

ENV NODE_ENV=production

EXPOSE 8080

CMD ["npm", "start"]
```

### Short Memory

```text
FROM       → Base image
WORKDIR    → Working directory
COPY       → Copy files
RUN        → Build/install command
ENV        → Environment variable
ARG        → Build-time variable
EXPOSE     → Document application port
CMD        → Default command
ENTRYPOINT → Main executable
```

### ⭐ Dockerfile — Multi-Stage

```dockerfile
FROM node:22-alpine AS build

WORKDIR /app
COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

FROM nginx:alpine

COPY --from=build /app/dist /usr/share/nginx/html

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

### ⭐ Docker Compose

```yaml
services:
  app:
    build: .
    ports:
      - "8080:8080"
    environment:
      NODE_ENV: production
    restart: unless-stopped
```

### Short Memory

```text
Image  → Application package
Container → Running instance of image
Volume → Persistent data
Network → Container communication
Compose → Multi-container application
```

### ⭐ main.tf

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}

provider "aws" {
  region = "ap-south-1"
}

resource "aws_instance" "app" {
  ami           = "ami-xxxxxxxx"
  instance_type = var.instance_type

  tags = {
    Name = "dev-server"
  }
}
```

```hcl
variable "instance_type" {
  type    = string
  default = "t3.micro"
}
```

### ⭐ outputs.tf

```hcl
output "instance_id" {
  value = aws_instance.app.id
}
```

### ⭐ terraform.tfvars

```hcl

```

## 7. Ansible

<a id="7. Ansible"></a>

### ⭐ Important Keywords

`inventory` → `playbook` → `hosts` → `become` → `tasks` → `module`  
`vars` → `register` → `when` → `loop` → `handlers` → `notify` → `roles` → `tags`

### ⭐ Inventory

```ini
[web]
web01 ansible_host=192.168.1.10
web02 ansible_host=192.168.1.11

[app]
app01 ansible_host=192.168.1.20
```

### ⭐ Playbook

```yaml
---
- name: Install and start Nginx
  hosts: web
  become: true

  tasks:
    - name: Install nginx
      apt:
        name: nginx
        state: present
        update_cache: true

    - name: Start nginx
      service:
        name: nginx
        state: started
        enabled: true
```

### ⭐ Variables + Condition

```yaml
---
- name: Configure application
  hosts: app
  become: true

  vars:
    app_port: 8080

  tasks:
    - name: Start application
      service:
        name: myapp
        state: started
      when: app_port == 8080
```

### ⭐ Handler
