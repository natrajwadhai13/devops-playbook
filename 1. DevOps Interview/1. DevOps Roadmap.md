## 1. Git

### ⭐ Important Keywords

`clone` `init` `status` `add` `commit` `push` `pull` `fetch`  
`branch` `checkout` `switch` `merge` `rebase` `stash` `tag`  
`remote` `log` `diff` `reset` `revert` `cherry-pick`

### ⭐ Basic Commands

```bash
git clone <repo-url>
git status
git add .
git commit -m "message"
git push origin main
git pull origin main
git fetch
git branch
git switch -c feature/login
git merge feature/login
git stash
git log --oneline
```

### Short Memory

```text
clone  → Get repository
add    → Stage changes
commit → Save changes locally
push   → Send commits to remote
pull   → Fetch + merge remote changes
fetch  → Download remote changes only
merge  → Combine branches
rebase → Reapply commits on another base
stash  → Temporarily save changes
```

## 3. Bash / Shell Scripting

### ⭐ Important Keywords

`#!/bin/bash` `variable` `if` `elif` `else` `for` `while`  
`case` `function` `$?` `$1` `$@` `exit` `read` `echo`

### ⭐ Basic Script

```bash
#!/bin/bash

APP_NAME="myapp"

if [ -f "$APP_NAME.jar" ]; then
    echo "Application file exists"
else
    echo "Application file not found"
fi

echo "Exit code: $?"
```

### ⭐ Deployment-Style Script

```bash
#!/bin/bash

set -e

APP_NAME="myapp"
APP_DIR="/opt/$APP_NAME"

echo "Starting deployment"

cd "$APP_DIR"

./stop.sh
./backup.sh
./start.sh

echo "Deployment completed"
```

### Short Memory

```text
$?   → Previous command exit status
$1   → First argument
$@   → All arguments
-f   → File exists
-d   → Directory exists
-e   → Exit on command failure with set -e
```

## 4. Docker

### ⭐ Important Keywords

`FROM` `WORKDIR` `COPY` `ADD` `RUN` `ENV` `ARG`  
`EXPOSE` `CMD` `ENTRYPOINT` `USER` `VOLUME` `HEALTHCHECK`

### ⭐ Dockerfile — Basic

```dockerfile
FROM node:22-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install

COPY . .

ENV NODE_ENV=production

EXPOSE 8080

CMD ["npm", "start"]
```

### Short Memory

```text
FROM       → Base image
WORKDIR    → Working directory
COPY       → Copy files
RUN        → Build/install command
ENV        → Environment variable
ARG        → Build-time variable
EXPOSE     → Document application port
CMD        → Default command
ENTRYPOINT → Main executable
```

### ⭐ Dockerfile — Multi-Stage

```dockerfile
FROM node:22-alpine AS build

WORKDIR /app
COPY package*.json ./
RUN npm ci

COPY . .
RUN npm run build

FROM nginx:alpine

COPY --from=build /app/dist /usr/share/nginx/html

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

### ⭐ Docker Compose

```yaml
services:
  app:
    build: .
    ports:
      - "8080:8080"
    environment:
      NODE_ENV: production
    restart: unless-stopped
```

### Short Memory

```text
Image  → Application package
Container → Running instance of image
Volume → Persistent data
Network → Container communication
Compose → Multi-container application
```

```yaml

  name: myapp

  replicas: 2

  selector:
    matchLabels:
      app: myapp

  template:

      labels:

    spec:
      containers:
        - name: myapp
          image: myapp:1.0
          ports:
            - containerPort: 8080
```

### ⭐ Service YAML

```yaml
apiVersion: v1
kind: Service

metadata:
  name: myapp-service

spec:
  selector:
    app: myapp

  ports:
    - port: 80
      targetPort: 8080

  type: ClusterIP
```

### ⭐ ConfigMap

```yaml

  name: myapp-config

  APP_ENV: "dev"
  LOG_LEVEL: "info"
```

### ⭐ Secret

```yaml

  name: myapp-secret

  DB_USER: admin
  DB_PASSWORD: password
```

### ⭐ Ingress

```yaml
apiVersion: networking.k8s.io/v1

metadata:
  name: myapp-ingress

spec:
  rules:
    - host: myapp.example.com
      http:
        paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: myapp-service
                port:
                  number: 80
```

### Short Memory


## 7. Ansible

### ⭐ Important Keywords

`inventory` `playbook` `hosts` `become` `tasks` `module`  
`vars` `register` `when` `loop` `handlers` `notify` `roles` `tags`

### ⭐ Inventory

```ini
[web]
web01 ansible_host=192.168.1.10
web02 ansible_host=192.168.1.11

[app]
app01 ansible_host=192.168.1.20
```

### ⭐ Playbook

```yaml
---
- name: Install and start Nginx
  hosts: web
  become: true

  tasks:
    - name: Install nginx
      apt:
        name: nginx
        state: present
        update_cache: true

    - name: Start nginx
      service:
        name: nginx
        state: started
        enabled: true
```

### ⭐ Variables + Condition

```yaml
---
- name: Configure application
  hosts: app
  become: true

  vars:
    app_port: 8080

  tasks:
    - name: Start application
      service:
        name: myapp
        state: started
      when: app_port == 8080
```

### ⭐ Handler

```yaml
tasks:
  - name: Update nginx configuration
    template:
      src: nginx.conf.j2
      dest: /etc/nginx/nginx.conf
    notify: Restart nginx

handlers:
  - name: Restart nginx
    service:
      name: nginx
      state: restarted
```

### Short Memory

```text
Inventory → Target hosts
Playbook  → Automation instructions
Hosts     → Where task runs
Become    → Privilege escalation
Tasks     → Work to perform
Module    → Ansible action
Vars      → Variables
When      → Condition
Loop      → Repeat task
Handler   → Triggered action
Role      → Reusable Ansible structure
```

## 8. Jenkins

### ⭐ Important Keywords

`pipeline` `agent` `stages` `stage` `steps` `post`  
`environment` `parameters` `triggers` `when` `input` `tools`

### ⭐ Jenkinsfile — Basic

```groovy
pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Docker Build') {
            steps {
                sh 'docker build -t myapp:latest .'
            }
        }

        stage('Deploy') {
            steps {
                sh './deploy.sh'
            }
        }
    }

    post {
        always {
            echo 'Pipeline completed'
        }
    }
}
```

### ⭐ Jenkinsfile — Environment + Manual Deploy

```groovy
pipeline {
    agent any

    environment {
        APP_NAME = 'myapp'
        ENV_NAME = 'production'
    }

    stages {
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }

        stage('Deploy') {
            when {
                branch 'main'
            }

            steps {
                input message: 'Deploy to production?'
                sh './deploy.sh'
            }
        }
    }
}
```

### Short Memory

```text
pipeline     → Complete pipeline
agent        → Where pipeline runs
stages       → Pipeline phases
stage        → Individual phase
steps        → Commands/actions
environment  → Environment variables
parameters   → User inputs
triggers     → Pipeline triggers
when         → Conditional execution
post         → Post-build actions
```

### ⭐ .gitlab-ci.yml

```yaml
stages:
  - build
  - test
  - scan
  - docker
  - deploy

  APP_NAME: "myapp"

build:
  stage: build
  script:
    - mvn clean package
  artifacts:
    paths:
      - target/*.jar

test:
  stage: test
  script:
    - mvn test

scan:
  stage: scan
  script:
    - echo "Run security scan"

docker_build:
  stage: docker
  script:
    - docker build -t $APP_NAME:$CI_COMMIT_SHA .

  stage: deploy
  script:
    - ./deploy.sh
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'
  when: manual
```

```yaml
include:
  - local: ".gitlab-ci/build.yml"
```

```text

include   → Reusable CI configuration
```
