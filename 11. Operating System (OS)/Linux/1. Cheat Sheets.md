# Linux Cheat Sheets for Linux Administrators & DevOps Engineers

Practical command reference for Ubuntu/Debian and RHEL-family Linux systems. Commands requiring elevated privileges use `sudo`. Verify targets before running destructive commands.

## 1. System Information and Help

| Command               | Purpose                     | Example               |
| --------------------- | --------------------------- | --------------------- |
| `man COMMAND`         | Open manual                 | `man ls`              |
| `COMMAND --help`      | Show usage                  | `ip --help`           |
| `type COMMAND`        | Identify shell command type | `type cd`             |
| `which COMMAND`       | Locate executable           | `which nginx`         |
| `uname -a`            | Kernel/system information   | `uname -a`            |
| `uname -r`            | Kernel release              | `uname -r`            |
| `cat /etc/os-release` | Distribution/version        | `cat /etc/os-release` |
| `hostnamectl`         | Hostname and OS details     | `hostnamectl`         |
| `uptime`              | Uptime and load averages    | `uptime`              |
| `date`                | Current date/time           | `date`                |
| `timedatectl`         | Time and timezone status    | `timedatectl`         |
| `whoami`              | Current username            | `whoami`              |
| `id USER`             | UID, GID and groups         | `id appuser`          |
| `lscpu`               | CPU details                 | `lscpu`               |
| `lsmem`               | Memory block information    | `lsmem`               |

## 2. Navigation and File Operations

| Command             | Purpose                                    | Example                           |
| ------------------- | ------------------------------------------ | --------------------------------- |
| `pwd`               | Print current directory                    | `pwd`                             |
| `ls -l`             | Long listing                               | `ls -l /var/log`                  |
| `ls -lah`           | Include hidden files, human-readable sizes | `ls -lah`                         |
| `cd /path`          | Change directory                           | `cd /etc`                         |
| `cd ..`             | Parent directory                           | `cd ..`                           |
| `cd ~`              | Home directory                             | `cd ~`                            |
| `cd -`              | Previous directory                         | `cd -`                            |
| `mkdir DIR`         | Create directory                           | `mkdir reports`                   |
| `mkdir -p a/b/c`    | Create parent directories                  | `mkdir -p /opt/app/logs`          |
| `rmdir DIR`         | Remove empty directory                     | `rmdir olddir`                    |
| `touch FILE`        | Create empty file/update timestamp         | `touch app.log`                   |
| `cp SRC DEST`       | Copy file                                  | `cp app.conf app.conf.bak`        |
| `cp -r SRC DEST`    | Copy directory recursively                 | `cp -r app/ app-copy/`            |
| `cp -a SRC DEST`    | Preserve attributes when copying           | `cp -a /etc/app /backup/`         |
| `mv SRC DEST`       | Move or rename                             | `mv old.txt new.txt`              |
| `rm FILE`           | Remove file                                | `rm temp.txt`                     |
| `rm -r DIR`         | Remove directory tree                      | `rm -r olddir`                    |
| `file FILE`         | Identify file type                         | `file archive.tar.gz`             |
| `stat FILE`         | File metadata                              | `stat /etc/passwd`                |
| `readlink -f PATH`  | Resolve absolute path                      | `readlink -f /usr/bin/python3`    |
| `ln -s TARGET LINK` | Create symbolic link                       | `ln -s /opt/app/current app-link` |

**Safety:** `rm -rf` can permanently delete large directory trees. Verify the full path before running it, especially as root.

## 3. View and Edit Files

| Command                | Purpose                               | Example                        |
| ---------------------- | ------------------------------------- | ------------------------------ |
| `cat FILE`             | Print full file                       | `cat /etc/hosts`               |
| `less FILE`            | Read page by page                     | `less /var/log/syslog`         |
| `head FILE`            | First 10 lines                        | `head app.log`                 |
| `head -n 50 FILE`      | First 50 lines                        | `head -n 50 app.log`           |
| `tail FILE`            | Last 10 lines                         | `tail app.log`                 |
| `tail -n 100 FILE`     | Last 100 lines                        | `tail -n 100 app.log`          |
| `tail -f FILE`         | Follow appended log entries           | `tail -f app.log`              |
| `tail -F FILE`         | Follow across log rotation/recreation | `tail -F app.log`              |
| `nl -ba FILE`          | Number all lines                      | `nl -ba config.yml`            |
| `wc -l FILE`           | Count lines                           | `wc -l app.log`                |
| `vi FILE` / `vim FILE` | Edit file                             | `sudo vi /etc/ssh/sshd_config` |

## 4. Search and Text Processing

| Command                  | Purpose                            | Example                                  |
| ------------------------ | ---------------------------------- | ---------------------------------------- | ---------------- |
| `grep "text" FILE`       | Search text                        | `grep "ERROR" app.log`                   |
| `grep -i`                | Case-insensitive                   | `grep -i "failed" app.log`               |
| `grep -n`                | Include line numbers               | `grep -n "listen" nginx.conf`            |
| `grep -v`                | Exclude matching lines             | `grep -v "^#" config.conf`               |
| `grep -r`                | Recursive search                   | `grep -r "server_name" /etc/nginx`       |
| `grep -E`                | Extended regular expressions       | `grep -E "error                          | failed" app.log` |
| `find PATH -name NAME`   | Find by name                       | `find /var/log -name "*.log"`            |
| `find PATH -type f`      | Find regular files                 | `find /opt/app -type f`                  |
| `find PATH -type d`      | Find directories                   | `find /opt -type d`                      |
| `find PATH -mtime -1`    | Modified within one day            | `find /var/log -type f -mtime -1`        |
| `find PATH -size +100M`  | Files larger than 100 MB           | `find / -type f -size +100M 2>/dev/null` |
| `sort FILE`              | Sort lines                         | `sort names.txt`                         |
| `sort -n FILE`           | Numeric sort                       | `sort -n numbers.txt`                    |
| `uniq -c`                | Count adjacent duplicates          | `sort names.txt \| uniq -c`              |
| `cut -d: -f1 FILE`       | Extract delimited field            | `cut -d: -f1 /etc/passwd`                |
| `awk '{print $1}' FILE`  | Print first field                  | `awk '{print $1}' access.log`            |
| `sed 's/old/new/g' FILE` | Replace text in output             | `sed 's/dev/prod/g' app.conf`            |
| `tee FILE`               | Write output to screen and file    | `ip addr \| tee ip.txt`                  |
| `xargs`                  | Build command arguments from input | `printf '%s\\n' a b \| xargs -n1 echo`   |

Useful log searches:

```bash

awk '$9 == 500 {count++} END {print count+0}' /var/log/nginx/access.log
```

## 5. Permissions, Ownership and ACL

Linux permissions apply to user (u), group (g) and others (o).

| Permission | Letter | Numeric value | Meaning                                      |
| ---------- | -----: | ------------: | -------------------------------------------- |
| Read       |    `r` |             4 | Read file; list directory names              |
| Write      |    `w` |             2 | Modify file; create/remove directory entries |
| Execute    |    `x` |             1 | Execute file; traverse directory             |

| Command                     | Purpose                      | Example                                   |
| --------------------------- | ---------------------------- | ----------------------------------------- |
| `ls -l`                     | View permissions/ownership   | `ls -l script.sh`                         |
| `chmod 755 FILE`            | Owner rwx, group/others r-x  | `chmod 755 script.sh`                     |
| `chmod 644 FILE`            | Owner rw-, group/others r--  | `chmod 644 app.conf`                      |
| `chmod u+x FILE`            | Add owner execute            | `chmod u+x deploy.sh`                     |
| `chmod -R 750 DIR`          | Recursive permissions        | `chmod -R 750 /opt/app`                   |
| `chown USER FILE`           | Change owner                 | `sudo chown appuser app.log`              |
| `chown USER:GROUP FILE`     | Change owner and group       | `sudo chown appuser:appgroup app.log`     |
| `chown -R USER:GROUP DIR`   | Recursive ownership          | `sudo chown -R appuser:appgroup /opt/app` |
| `chgrp GROUP FILE`          | Change group                 | `sudo chgrp developers app.conf`          |
| `umask`                     | Show default permission mask | `umask`                                   |
| `getfacl FILE`              | Read ACL                     | `getfacl shared.txt`                      |
| `setfacl -m u:USER:rw FILE` | Add user ACL                 | `setfacl -m u:alice:rw shared.txt`        |
| `setfacl -x u:USER FILE`    | Remove user ACL entry        | `setfacl -x u:alice shared.txt`           |
| `setfacl -b FILE`           | Remove extended ACL entries  | `setfacl -b shared.txt`                   |

Special permissions:

| Permission | Numeric form | Meaning                                                                                         |
| ---------- | -----------: | ----------------------------------------------------------------------------------------------- |
| SUID       |         4xxx | Executable runs with file owner's effective UID                                                 |
| SGID       |         2xxx | Executable uses file group's effective GID; on directories, new entries inherit directory group |
| Sticky bit |         1xxx | In shared directories, users generally remove only their own entries                            |

```bash
sudo chmod 4755 /path/to/program
sudo chmod 2775 /shared/team
sudo chmod 1777 /shared/tmp
```

## 7. Process Management

| Command              | Purpose                                  | Example                          |
| -------------------- | ---------------------------------------- | -------------------------------- |
| `ps -ef`             | List processes                           | `ps -ef`                         |
| `ps aux`             | Detailed process listing                 | `ps aux`                         |
| `ps -p PID -f`       | Inspect one process                      | `ps -p 1234 -f`                  |
| `pgrep NAME`         | Find process IDs                         | `pgrep nginx`                    |
| `pidof NAME`         | Find process IDs                         | `pidof sshd`                     |
| `top`                | Live process/resource view               | `top`                            |
| `htop`               | Interactive process viewer, if installed | `htop`                           |
| `kill PID`           | Send SIGTERM by default                  | `kill 1234`                      |
| `kill -9 PID`        | Send SIGKILL                             | `kill -9 1234`                   |
| `pkill NAME`         | Signal processes by pattern              | `pkill -TERM nginx`              |
| `killall NAME`       | Signal processes by name                 | `killall nginx`                  |
| `nice -n 10 COMMAND` | Start with adjusted niceness             | `nice -n 10 ./job.sh`            |
| `renice 5 -p PID`    | Change process niceness                  | `sudo renice 5 -p 1234`          |
| `jobs`               | List shell jobs                          | `jobs`                           |
| `COMMAND &`          | Run in background                        | `sleep 300 &`                    |
| `bg %1` / `fg %1`    | Resume background / foreground job       | `fg %1`                          |
| `nohup COMMAND &`    | Ignore hangup signal                     | `nohup ./job.sh >job.log 2>&1 &` |

Prefer SIGTERM first. Use SIGKILL only when a process will not stop and you understand the consequences.

## 10. LVM Administration

LVM flow: **Disk/Partition → Physical Volume (PV) → Volume Group (VG) → Logical Volume (LV) → Filesystem → Mount point**

| Command                     | Purpose                                 | Example                                     |
| --------------------------- | --------------------------------------- | ------------------------------------------- |
| `pvs` / `pvdisplay`         | Show PVs                                | `sudo pvs`                                  |
| `pvcreate DEVICE`           | Initialize PV                           | `sudo pvcreate /dev/sdb`                    |
| `vgs` / `vgdisplay`         | Show VGs                                | `sudo vgs`                                  |
| `vgcreate VG PV`            | Create VG                               | `sudo vgcreate vgdata /dev/sdb`             |
| `vgextend VG PV`            | Add PV to VG                            | `sudo vgextend vgdata /dev/sdc`             |
| `lvs` / `lvdisplay`         | Show LVs                                | `sudo lvs`                                  |
| `lvcreate -L SIZE -n LV VG` | Create LV                               | `sudo lvcreate -L 10G -n lvapp vgdata`      |
| `lvextend -L +SIZE LV`      | Extend LV                               | `sudo lvextend -L +5G /dev/vgdata/lvapp`    |
| `lvextend -r -L +SIZE LV`   | Extend LV and attempt filesystem resize | `sudo lvextend -r -L +5G /dev/vgdata/lvapp` |
| `lvremove LV`               | Remove LV                               | `sudo lvremove /dev/vgdata/lvapp`           |

Do not reduce an LV containing a mounted XFS filesystem. XFS cannot be shrunk. Reducing ext4 requires an unmounted filesystem and a carefully ordered filesystem/LV procedure with verified backups.

## 23. Quick Production Troubleshooting

| Symptom              | First commands                                                |
| -------------------- | ------------------------------------------------------------- |
| Server is slow       | `uptime`, `top`, `free -h`, `vmstat 1 5`                      |
| High CPU             | `top`, `ps -eo pid,ppid,cmd,%cpu --sort=-%cpu \| head`        |

| Disk full            | `df -hT`, `du -xhd1 /var 2>/dev/null`, `lsblk`                |
| Inodes exhausted     | `df -ih`, `find /var -xdev -type f \| wc -l`                  |
| Port unavailable     | `sudo ss -lntup`, `sudo lsof -i :PORT`                        |

| DNS issue            | `getent hosts DOMAIN`, `dig DOMAIN`, `resolvectl status`      |
| Network issue        | `ip addr`, `ip route`, `ping`, `curl -v URL`                  |
| Filesystem read-only | `findmnt`, `dmesg -T`, `journalctl -k`                        |
| Boot issue           | `journalctl -b -p err`, `systemctl --failed`, `dmesg -T`      |

Replace placeholders such as `SERVICE`, `PORT` and `DOMAIN` with actual values. SSH service names and log locations vary by distribution.

## 27. Production Safety Checklist

- Confirm the server, environment and current user.
- Verify the exact device, mount point, PID, service name or file path.
- Read command help/manual pages if unfamiliar.
- Take and verify backups before data or configuration changes.
- Use a change plan and maintenance window for risky operations.
- Use `sudo` only when required; avoid unnecessary root sessions.
- Validate configuration before reload/restart where supported.
- Check service status and logs after the change.
- Record the change and outcome.
