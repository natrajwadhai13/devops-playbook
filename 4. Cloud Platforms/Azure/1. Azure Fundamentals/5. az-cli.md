# 📘 **Azure CLI – Complete Notes**

---

## ☁️ **What is Azure CLI?**

**Azure CLI (Command-Line Interface)** is a **cross-platform command-line tool** used to **create, manage, and automate Azure resources**.

You can use it on:

* Windows
* Linux
* macOS
* Cloud Shell

It works with **Microsoft Azure** services.

---

## ❓ **Why Azure CLI?**

Azure CLI is used because it allows you to manage Azure **faster and more accurately** than the portal.

### **Main Reasons**

* Faster than portal
* Repeatable commands
* Easy automation
* Script-friendly
* Less manual mistakes

---

## ✅ **Advantages of Azure CLI**

### ⚡ **1. Quick Action**

* Create VM, Storage, VNet in seconds
* No clicking through portal UI

**Example**

```bash
az group create --name myRG --location eastus
```

---

### 🤖 **2. Automation**

* Used in:

  * Shell scripts
  * CI/CD pipelines
  * DevOps automation
* Same command can be reused multiple times

**Example**

```bash
az vm start --name myVM --resource-group myRG
```

---

### ❌ **3. Reduces Configuration Errors**

* No manual clicking
* Same command = same result every time
* Ideal for **Infrastructure as Code**

---

## 🧩 **Azure CLI Architecture (Simple)**

```
User → Azure CLI → Azure Resource Manager → Azure Resources
```

---

## 💻 **Azure CLI Installation**

### 🔹 **Option 1: Install on Local Machine**

#### **Windows**

* Download MSI from Microsoft
* Or use:

```powershell
winget install Microsoft.AzureCLI
```

#### **Linux**

```bash
curl -sL https://aka.ms/InstallAzureCLIDeb | sudo bash
```

#### **macOS**

```bash
brew install azure-cli
```

---

### 🔹 **Option 2: Azure Cloud Shell (No Install)**

* Login to Azure Portal
* Click **Cloud Shell**
* Choose **Bash**
* Azure CLI is already installed

---

## 🔐 **Azure CLI Login**

### **Login Command**

```bash
az login
```

* Opens browser for authentication
* After login, CLI connects to your Azure account

### **Check Account**

```bash
az account show
```

### **List Subscriptions**

```bash
az account list
```

### **Set Subscription**

```bash
az account set --subscription "subscription-name"
```

---

## 🧱 **Basic Azure CLI Structure**

```
az <group> <command> <subcommand> --parameter value
```

**Example**

```bash
az vm list --output table
```

---

## 🧪 **Common Azure CLI Commands**

### 🔹 **Resource Group**

```bash
az group create --name myRG --location eastus
az group list
az group delete --name myRG
```

---

### 🔹 **Virtual Machine**

```bash
az vm create --resource-group myRG --name myVM --image UbuntuLTS --admin-username azureuser
az vm start --name myVM --resource-group myRG
az vm stop --name myVM --resource-group myRG
```

---

### 🔹 **Storage Account**

```bash
az storage account create \
--name mystorage123 \
--resource-group myRG \
--location eastus \
--sku Standard_LRS
```

---

### 🔹 **Networking (VNet)**

```bash
az network vnet create \
--resource-group myRG \
--name myVnet \
--address-prefix 10.0.0.0/16
```
